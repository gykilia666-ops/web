
КАК ВЫПОЛНЕНЫ УСЛОВИЯ
Яхта нарисована HTML-элементами с CSS: clip-path, border-radius,
фоновыми цветами, градиентами и псевдоэлементами. Нет img, SVG,
canvas, фоновых изображений или внешних ресурсов.
Используются animation, transform, transition и @keyframes.
CSS подключён из отдельного файла style.css.
В HTML нет атрибутов style: оформление целиком вынесено в style.css.

ЧАСЫ
Часовая стрелка: один оборот за 43200 секунд (12 часов).
Минутная стрелка: один оборот за 3600 секунд (1 час).
Секундная стрелка: один оборот за 60 секунд.
При открытии JavaScript устанавливает начальные углы по времени устройства.
Дальнейшее движение стрелок выполняется CSS-анимацией.
Пауза останавливает стрелки, продолжение возобновляет движение.
Кнопка «Текущее время» повторно синхронизирует часы с устройством.
