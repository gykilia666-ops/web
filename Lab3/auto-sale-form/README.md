# Адаптивная форма продажи автомобиля

Учебное задание из task-2.docx. Вариант 5.

## Условия
- Разработать адаптивную форму регистрации автомобиля для продажи.
- Использовать не менее 8 различных тегов для форм.
- Использовать не менее 5 различных значений type у input.
- Мобильная и десктопная версии должны отличаться. В документе дан пример: label на компьютере, placeholder вместо видимых подписей на телефоне.

## Запуск
Откройте index.html в браузере. Сервер и интернет не нужны.
CSS подключён из css/style.css, JavaScript — из js/script.js.
Не переносите index.html отдельно от папок css и js.
Чтобы сохранить предыдущую работу, поместите всю папку auto-sale-form в репозиторий, не заменяя старые HTML-страницы.

## Реализация
12 тегов: form, fieldset, legend, label, input, select, option, optgroup, textarea, button, datalist, output.
10 типов input: text, number, radio, checkbox, date, url, file, range, tel, email.
При ширине от 768px используются две колонки и отдельные label для полей.
При ширине меньше 768px — одна колонка; обычные подписи полей скрыты, текстовые поля используют placeholder. Кнопки и группы выбора перестраиваются вертикально.
Подписи radio и checkbox остаются видимыми: это варианты выбора, а не отдельные подписи текстовых полей.
Для date и range показаны короткие мобильные пояснения; select имеет пункт-подсказку, file — видимое описание.
Каждое обычное поле имеет aria-label; label сохраняется в разметке.

## Возможности
Сведения об автомобиле, цена, город, описание, фото, ссылка на видео, срок объявления, контакты продавца.
Обязательные поля, числовые ограничения, проверка email, телефона и необязательного VIN.
Для электромобиля поле объёма двигателя отключается, скрывается и перестаёт быть обязательным.
Фотографии: до 5 файлов JPEG, PNG или WebP; не более 5 МБ каждый.
Кнопка «Проверить объявление» создаёт локальный предпросмотр.
Кнопка «Очистить форму» очищает поля и возвращает настройки по умолчанию.
Проверка работает в браузере, публикации и загрузки файлов на сервер нет.

## Важно
Задание требует форму, а не серверную систему объявлений. бэкенда и БД нет
