# PHP: история, возможности и примеры кода

Учебная статья, выполненная на HTML и CSS. Вариант 5 — PHP.

## Запуск

Требуется Python 3 и доступ к интернету для первоначальной загрузки
normalize.css и локального файла шрифта.

1. Откройте терминал в каталоге проекта.
2. Выполните:

   python prepare.py

3. Запустите локальный сервер:

   python -m http.server 8000

4. Откройте http://localhost:8000

Также после подготовки ресурсов можно открыть index.html напрямую.

После запуска prepare.py все ресурсы сайта находятся в репозитории:
страница не использует CDN, удалённые картинки или Google Fonts API.

Чтобы передать полностью автономную версию проекта, добавьте скачанные
ресурсы в репозиторий:

    git add .
    git commit -m "Добавлена статья о PHP"

## Файлы

- index.html — статья и семантическая разметка.
- styles.css — оформление, адаптивность и подсветка кода.
- prepare.py — загрузка normalize.css, шрифта Oswald и его лицензии.
- assets/*.svg — собственные иллюстрации и маркер списка.
- assets/fonts/Oswald.ttf — локальный шрифт заголовков.
- assets/fonts/OFL.txt — лицензия шрифта.

## Проверка требований

- Разделы: история создания, обзор языка, примеры кода.
- Содержание: список якорных ссылок.
- Три иллюстрации: слева и справа с обтеканием, по центру — отдельным блоком.
- Таблица с заголовком, чередованием строк, границами и подсветкой.
- Нумерованный, стандартный маркированный и графический списки.
- Размеры: h1 — 24px, h2 — 18px, основной текст — 14px.
- Локальный нестандартный шрифт подключён через @font-face.
- Внутренние и внешние ссылки.
- Более 30 различных HTML-тегов и 40 CSS-свойств.
- Статическая цветовая подсветка PHP-кода.
- normalize.css подключён перед основными стилями.
- В конце статьи перечислены использованные теги и CSS-свойства.

В узком окне обтекание отключается для удобства чтения.

Образец оформления таблицы в условии не приложен, поэтому использовано
самостоятельное оформление. При необходимости его можно заменить
в блоке стилей таблицы.
